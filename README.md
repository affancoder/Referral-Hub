# Referral-Hub

A modern, responsive referral management dashboard built with **React.js** and **Vite**. Referral-Hub provides a clean interface for submitting referrals, tracking referral progress, viewing rewards, and managing user profile information.

## 🚀 Features

- **Login Page** — User-friendly login interface.
- **Dashboard** — Overview of referral activity and key statistics.
- **Submit Referral** — Submit new client referrals through a structured form.
- **My Referrals** — View, search, filter, and track submitted referrals.
- **Referral Details** — View detailed referral information and progress timelines.
- **Rewards** — Track referral rewards and view reward history.
- **Profile Management** — View and edit profile information.
- **Help & Support** — Search FAQs and submit demo support requests.
- **Responsive Design** — Interface adapted for desktop and mobile screens.

## 🛠️ Tech Stack

- **React.js** — Frontend UI library
- **Vite** — Development server and build tool
- **React Router DOM** — Client-side routing
- **Lucide React** — Icons
- **CSS3** — Styling and responsive layouts
- **JavaScript (ES6+)** — Application logic

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git (optional)

### 1. Clone the repository

```bash
git clone https://github.com/affancoder/Referral-Hub.git
```

### 2. Navigate to the project folder

```bash
cd Referral-Hub
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173`.

## 🏗️ Build for Production

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## 🧪 Code Quality

Run ESLint to check the project for potential code issues:

```bash
npm run lint
```

## 📌 Project Status

**Frontend Demo**

Referral-Hub is currently a frontend project using sample data and local UI interactions. Backend services, database integration, real authentication, and actual referral or reward processing are not connected.
